# Chef Claude Recipe Book

A recipe app where you can browse and view cooking recipes with ingredients and instructions.

## How to Run

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Open your browser and navigate to the URL shown in the terminal (usually http://localhost:5173)

## Features

- Browse recipe cards
- Click on a recipe to see details
- View ingredients and cooking instructions
- Simple and clean interface
