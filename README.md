# Meme Generator

A  meme generator app where you can add text to random meme images.

## How to Run

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Open your browser and navigate to the URL shown in the terminal (usually http://localhost:5173)

## Features

- Generate random meme images
- Add top and bottom text to memes
- Simple and fun interface
